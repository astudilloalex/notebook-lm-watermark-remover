# NotebookLM Studio @VERSION@

Install NotebookLM Studio without unpacking a portable folder. Python, FFmpeg and ffprobe are included in every installer. Open the installed application from the Start menu, applications menu or Applications folder. A web browser is required.

Open the installer and follow its steps. Windows installs for the current user with a Start menu shortcut and uninstaller. Linux uses your distribution's graphical package installer; Mac installs into Applications. [Installation and update guide](https://github.com/@REPOSITORY@/blob/v@VERSION@/docs/INSTALLATION.md).

**Signing status:** Windows and Mac installers are unsigned; Mac packages are not notarized. Your operating system may require an explicit security approval. No signing certificates or notarization credentials have been provided.

## Changes

- Native Windows, DEB/RPM and Mac installers, plus shortcuts/menu integration.
- Automatic installer generation and public release publication through GitHub Actions.
- English repository documentation, installer messages, build steps and release notes.
- Documentation and third-party notices are included in the installed payload.
- Installed-app checks cover batch processing/downloads, session cleanup, reinstall and removal. RPM is tested with dependency resolution on Fedora 44; Mac upgrades remove obsolete bundle files.

The application supports mixed horizontal/Short batches, before/after previews, frame/second end trimming, and final-segment playback with audio. [User guide](https://github.com/@REPOSITORY@/blob/v@VERSION@/docs/USAGE.md).

## Download results before closing

Internal inputs, results and previews are temporary. Use the application's close button and confirm session deletion to stop the work, delete the session and request local-server shutdown. Undownloaded results are lost. Originals and downloaded copies outside the session are preserved. Closing the browser tab alone does not stop the server. Close the app before updating or uninstalling it.

## Portable alternatives and integrity

Portable archives remain available for [Windows](https://github.com/@REPOSITORY@/releases/download/v@VERSION@/NotebookLM-Studio-Windows-x64.zip), [Linux](https://github.com/@REPOSITORY@/releases/download/v@VERSION@/NotebookLM-Studio-Linux-x64.tar.gz), [Apple Silicon](https://github.com/@REPOSITORY@/releases/download/v@VERSION@/NotebookLM-Studio-macOS-AppleSilicon.zip) and [Intel Mac](https://github.com/@REPOSITORY@/releases/download/v@VERSION@/NotebookLM-Studio-macOS-Intel.zip). These optional archives still need full extraction. GitHub's Source code downloads are for development.

Every application/installer has a `.sha256` file. `verification-*.json` reports record portable, installed-app and installer-lifecycle checks. All four native targets pass the 35-test source suite and their package checks before publication. Exact third-party download hashes and notices are included under `LICENSES` inside each installation.
