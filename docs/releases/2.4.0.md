# NotebookLM Studio 2.4.0

Local batch processing for horizontal NotebookLM videos and Shorts, including before/after comparison, frame/second end trimming and final-segment preview with audio.

Packages are unsigned and Mac bundles are not notarized. GitHub's Source code downloads are for development.

## Features

- Multiple-file uploads and sequential batches containing horizontal videos and Shorts.
- Before/after image comparison and original/result playback.
- Per-video or selected-batch end trimming in frames or seconds.
- Preview the final seconds with audio and keep a precisely selected last frame.
- Individual MP4 downloads or one ZIP of completed results.
- Local FFmpeg processing without uploading videos to a cloud service.

Logo interpolation can leave a visible patch on detailed backgrounds; review the preview.

## Download before closing

Use the application's close button and confirm session deletion to stop work/transfers, remove internal inputs/results/previews and request local-server shutdown. Undownloaded results are lost. Originals and downloaded copies outside the session are preserved.

Closing only the browser tab does not stop the server. Sessions abandoned after an interrupted process are cleaned when the app next starts and their process lock is free.
